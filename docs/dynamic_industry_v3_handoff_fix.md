# Dynamic industry consumer v3 handoff boundary

Dynamic industries remain outside the fixed-theme assessment, persistence, overlap, constituent, and coverage universes. When the deterministic producer selects a company from a dynamic industry, the compatibility layer projects that industry into the existing price-signal contract only for Phase 5, Phase 6, and handoff generation.

The fixed-theme projection is generated independently and remains authoritative for Phases 1–4 and coverage. A second candidate projection supplies company rows and handoffs. Missing dynamic discovery ownership, conflicting bucket ownership, or an unsupported company-candidate theme ID fails closed.
